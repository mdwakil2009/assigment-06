# FitLog

FitLog is a workout management web application. Users can explore different workouts, view workout details, and create their own daily workout plan.

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* DaisyUI
* React icon

## Key Features

1. **Workout Library** – Explore different workouts.
2. **Workout Details** – View complete details about each workout.
3. **My Plan** – Add workouts to your personal workout plan.
4. **Saved Workouts** – Save workouts and remove them when needed.
5. **Workout Sorting** – Sort workouts by duration, calories, and rating.
