#  FitLog

### A Simple Workout Planning & Tracking Application

FitLog is a modern workout management application built with Next.js. It helps users explore different exercises, view detailed workout information, create a daily workout plan, and save workouts for later.

## 🛠️ Technologies Used

* Next.js – Application framework and routing
* React – Building user interfaces
* TypeScript – Type-safe development
* Tailwind CSS – Styling and responsive design
* DaisyUI – UI components
* REST API – Fetching workout data

##  Key Features

### 1.  Workout Library

Users can explore a collection of workouts with images, muscle groups, equipment, duration, calories, and ratings.

### 2.  Workout Details

Users can view complete workout details, including specifications and step-by-step instructions.

### 3.  My Plan

Users can add workouts to **Today's Plan** and manage their daily workout routine.

### 4.  Save Workouts

Users can save their favorite workouts for later and manage saved workouts easily.

### 5.  Sort Workouts

Users can sort workouts by **Duration, Calories, or Rating** to find exercises more easily.

##  Project Goal

The goal of FitLog is to provide a simple and user-friendly platform for discovering workouts and organizing a daily fitness routine.
